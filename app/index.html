GeneLedger

Verifiable species identification on Solana, then from DNA to protein to 3D structure. One marker gene, rpoB, does both jobs.

Start here (30 seconds)

  1. Click Load example sequence below. It is real DNA from E. coli O157:H7, the food-poisoning strain.
  2. Click ▶ Run pipeline.
  3. Scroll down. Each numbered box is one step from raw DNA to a 3D protein.

The idea: a lab sequences DNA from an unknown bacterium and wants to know what it is. Today that answer lives in private files that can be edited. GeneLedger puts the reference sequences and the result on the Solana blockchain, so the record is public, timestamped, tied to whoever submitted it, and cannot be quietly changed.
How Solana is used: the gene_ledger Solana program (in programs/gene_ledger) stores the reference sequences, scores the unknown read against them, and translates DNA to protein, saving each result with the submitter's wallet and a timestamp. This demo runs the same calculations in your browser so you can try it instantly.

input

DNA is a long string of four letters: A, C, G and T. A "read" is a short stretch of it that a sequencing machine has spelled out. Paste one below, or load the example.

2

Identify species

on-chain algorithm

We line the unknown read up against DNA from known species and count how many letters match. The highest score is the likely species. Pink ticks mark letters that differ. The references are the same gene (rpoB, first 180 letters) from three real bacteria, taken from the NCBI database. Labs do this with a tool called BLAST; this is a simplified version small enough to run on a blockchain.

3

Translate: primary structure

on-chain algorithm

Cells read DNA three letters at a time. Each triplet (a "codon") is the code for one amino acid, the building blocks of proteins. Each circle below is one amino acid; the chain of them is the protein. It works like a lookup table, which is why it can run as code on-chain.

Secondary structure

off-chain prediction

The amino-acid chain does not stay straight. Stretches of it curl into spirals (helices) or flatten into strands (sheets). This is a quick statistical estimate of which parts do what (Chou–Fasman method), not a full folding simulation.

Tertiary + quaternary structure

off-chain display

The helices and sheets fold into a 3D shape, and several folded chains lock together into a working machine. This is the real, lab-solved structure of E. coli RNA polymerase, the machine that reads genes (RCSB PDB 4YG2). The gene in this demo, rpoB, builds the pink chain. Drag to rotate.
